# trnorm demo

Yazılı Türkçeyi TTS modellerinin okuyabileceği okunuş formuna çevirir
(sayılar, tarihler, saatler, para, yüzde, sıra sayıları, kısaltmalar,
telefon numaraları...) ve ASR çıktısını rakamlı yazıya geri çevirir.

Kaynak kod ve ölçümler: https://github.com/ozguradmin/ahenk-turkish-tts
